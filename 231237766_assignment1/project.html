Team Project Proposal

Project Title

Student Registration & Module Management System

Project Description

The proposed system will allow a university to record student registrations, manage modules, assign lecturers, and capture marks. It will be built using PHP, MySQL, HTML, CSS, and JavaScript, and deployed on an Apache web server.

Project Objectives

  1. Design a normalized relational database (up to 3NF).
  2. Build a secure PHP back-end with prepared statements.
  3. Create a responsive front-end using HTML, CSS, and JavaScript.
  4. Implement user authentication (students, lecturers, admin).
  5. Generate reports (marks, registrations, module lists).

Technologies to Be Used

  • PHP 8.x (back-end)
  • MySQL (database)
  • HTML5, CSS3, JavaScript (front-end)
  • Apache (web server) & Tomcat (application server)
  • GitHub (version control)
